# 卷积性能

基准测试对卷积算子测量了什么，以及你将看到的数字背后的实现约束。

## 基准测试覆盖内容

`gpu_image_benchmark` 在每种图像尺寸（256×256 至 4096×4096）下测量以下基于卷积的操作：

- 高斯模糊 3×3（sigma 1.0）
- 高斯模糊 5×5（sigma 1.5）
- Sobel 边缘检测

所有报告值都是以毫秒为单位的 GPU 绝对延迟，经 10 次预热后对 100 次迭代取平均。基准测试不包含 CPU 或 OpenCV 参考实现，因此这里不给出加速比——请在自己的硬件上运行以获取你环境下的数据。

## 卷积核尺寸约束

卷积内核只接受**最大 7×7 的奇数尺寸**卷积核。`ConvolutionEngine::convolve`、`gaussianBlur` 和 `separableConvolve` 对更大或偶数尺寸抛出 `std::invalid_argument`（`src/operators/convolution_engine.cu`）。因此基准测试只测 3×3 和 5×5 高斯核；不修改内核代码就无法支持更大尺寸。

`src/operators/filters.cu` 中的相关滤波器各有自己的上限：中值滤波最大 7×7，盒式滤波和锐化最大 31×31。

## 优化说明

- 所有卷积路径都使用带边缘（halo）区域的共享内存分块
- `separableConvolve` 为可分离卷积核提供两趟（行 + 列）路径
- 卷积核尺寸上限为 7×7，当前不支持更大的卷积核
